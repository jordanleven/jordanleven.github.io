Force Refresh

October 2017

Force Refresh is a lightweight WordPress plugin born out of a simple necessity: the capability to prompt users to refresh their browsers on single-page applications. This plugin enables site owners to prompt users currently connected to their website to refresh their browsers. It achieves this by storing current site and page versions as hexadecimal representations of the time the refresh was requested. Subsequently, browsers periodically check if the stored site version matches the current site version, and if not, invoke a page refresh.

Force Refresh is an open-source plugin with a custom Vue-powered admin frontend. It utilizes a series of WordPress-flavored HTTP APIs for authentication and storing current site versions.
